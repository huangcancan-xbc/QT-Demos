# Demo 说明

复刻 Windows 的计算器。

## 1. 存在的问题

-   后续升级似乎需要一点精力，但是我是用 ui 制作的界面，所以整体来说，感觉 ui 升级比起代码制作的 ui 升级会稍微简单一点点。
-   计算逻辑主要是用 AI 完成，计算逻辑有点复杂，是真不想写，偷个懒吧，这个计算逻辑其实已经非常准确且接近市面上的计算器了，但是有些地方还需要做一点点优化，比如科学计数法的出现时机、小数点的保留数位等。
-   报错后不会等待一段时间消失，非要手动清除。这个其实比较简单，加一个显示时间 3S 就行。
-   计算完得出结果，想要计算下一个不相关的计算式，输入框也不会清空，属于逻辑判断了。
